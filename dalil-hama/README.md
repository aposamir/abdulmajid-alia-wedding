# دليل حماة — النسخة الجديدة

دليل خدمي سريع لأرقام وعناوين مدينة حماة: بحث فوري، اتصال وواتساب بلمسة، خريطة، «الأقرب إليّ»، ولوحة إدارة كاملة.

## ما الجديد مقارنة بالنسخة القديمة

| | القديم | الجديد |
|---|---|---|
| السرعة | كل بحث يذهب إلى الخادم | البحث يعمل داخل الجهاز على كل البيانات، فالنتائج فورية مع كل حرف. بعد أول زيارة تفتح الصفحة في أقل من ثانية ومن دون إنترنت |
| البحث | مطابقة نصية | يفهم «ة/ه» و«أ/ا» و«ى/ي» والتشكيل والأرقام الهندية، والمفرد والجمع («صيدلية» ← «صيدليات»)، والمرادفات («دكتور» ← عيادات، «كازية» ← محطات وقود، «فرن» ← مخابز)، والبحث برقم الهاتف بأي صيغة، وتصحيح الأخطاء الإملائية البسيطة، والبحث بالصوت |
| التصنيفات | 80 تصنيفاً متداخلاً | 45 تصنيفاً نظيفاً بأيقونات. أُعيد تصنيف أكثر من 400 نشاط كانت في «محلات وأسواق» و«أخرى» (مساجد، دوائر حكومية، محطات وقود، ذهب، بصريات...) |
| الأرقام | صيغ مختلطة (00963، +963، مسافات...) | صيغة موحّدة (09xxxxxxxx / 013xxxxxxx)، وزر واتساب تلقائي لأرقام الجوال |
| الموقع | روابط فقط | استُخرجت إحداثيات 1729 نشاطاً من روابط الخرائط وPlus Codes، فصار هناك عرض على الخريطة وترتيب حسب «الأقرب إليّ» |
| الإدارة | — | لوحة كاملة: طلبات، بلاغات، تعديل، دمج المكرر، جودة البيانات، إحصاءات، سجل تعديلات، استيراد وتصدير، عدة مشرفين |

## الميزات

**للزوار**
- بحث فوري ذكي (اسم، مهنة، حي، رقم) مع تمييز الكلمات المطابقة، وبحث بالصوت.
- بطاقات تحوي أزرار «اتصال» و«واتساب» (برسالة ترحيب جاهزة) و«الموقع» و«مشاركة» و«المفضلة».
- صفحة لكل نشاط بكل أرقامه، مع نسخ الرقم ونسخ المعلومات ومشاركتها، وعرض المسافة عنك.
- التصفح حسب التصنيف أو الحي، ورابط مباشر قابل للمشاركة لكل نشاط: `/?l=رقم`.
- «الأقرب إليّ»: ترتيب الأماكن حسب بعدها عن موقعك (لا يُحفظ موقعك على الخادم).
- عرض النتائج على الخريطة.
- أرقام الطوارئ في الصفحة الرئيسية.
- المفضلة، و«شاهدتها مؤخراً»، و«الأكثر تواصلاً»، و«أُضيفت حديثاً».
- «أضف نشاطك» (مع زر «موقعي» لتحديد مكان المحل تلقائياً)، و«أضف الرقم» للأنشطة التي لا رقم لها، و«إبلاغ عن خطأ».
- وضع ليلي، ويمكن تثبيته كتطبيق على الهاتف (PWA)، ويعمل دون إنترنت بعد أول زيارة.

**للإدارة** (`/admin/`)
- **الرئيسية:** مؤشرات، ومخطط الاتصالات والزيارات لآخر 30 يوماً، و«الأكثر تواصلاً»، و«بحثوا ولم يجدوا» (أي ما ينقص الدليل).
- **طلبات الإضافة:** قبول أو تعديل أو رفض، مع زر تحقق عبر واتساب أو اتصال، وتنبيه إن كان الرقم مكرراً.
- **البلاغات:** معالجتها، أو إخفاء النشاط، أو فتحه للتعديل مباشرة.
- **الأنشطة:** بحث وتصفية (حسب الحالة، والتصنيف، والحي، وما ينقصه رقم أو موقع أو حي، والمميز، والموثّق)، وتعديل جماعي (التصنيف، والحي، والحالة، والحذف)، ونموذج تعديل كامل فيه استخراج الإحداثيات من رابط الخريطة، ودمج المكرر، وسجل تعديلات كل نشاط.
- **جودة البيانات:** الأرقام المكررة، والأسماء المكررة، والأرقام غير الاعتيادية، والأنشطة الناقصة.
- **التصنيفات والأحياء:** إضافة وتعديل (أيقونة، وكلمات بحث، وترتيب) وحذف مع نقل الأنشطة.
- **استيراد وتصدير:** CSV (يفتح في Excel) وJSON، ويقبل الاستيراد ملفات النسخة القديمة أيضاً.
- **الإعدادات:** إعلان أعلى الصفحة، وأرقام الطوارئ، ووسائل التواصل، وفريق الإدارة (مالك أو محرر)، وتغيير كلمة المرور.

## البنية التقنية

```
dalil-hama/
├── public/                 ← الموقع (ملفات ثابتة، بلا خطوة بناء)
│   ├── index.html          ← الواجهة العامة
│   ├── admin/index.html    ← لوحة الإدارة
│   ├── assets/js/          ← app.js · admin.js · search.js · core.js · config.js
│   ├── assets/css/         ← app.css · admin.css
│   ├── sw.js               ← العمل دون إنترنت
│   └── manifest.webmanifest
├── supabase/migrations/    ← مخطط قاعدة البيانات والصلاحيات والدوال
├── scripts/                ← تنظيف بيانات CSV القديمة واستيرادها
├── docs/data-cleanup-report.md
└── render.yaml
```

- **الواجهة:** HTML وCSS وJavaScript حديث بلا أي مكتبات، فلا يُحمَّل إلا ما يلزم (الخريطة Leaflet تُحمَّل فقط عند طلبها).
- **البيانات:** Supabase (PostgreSQL) في فرانكفورت. القراءة العامة تمر حصراً عبر دالة `sync` التي لا تعيد إلا الأنشطة المنشورة وحقولها العامة. بيانات المُرسِلين والملاحظات الإدارية لا تخرج للعامة أبداً.
- **المزامنة:** أول زيارة تحمّل البيانات كلها (نحو 125 كيلوبايت مضغوطة)، والزيارات التالية تحمّل التغييرات فقط.
- **الأمان:** صلاحيات على مستوى الصفوف (RLS) لكل الجداول، وحدّ لعدد الطلبات والبلاغات من كل جهاز، وفخ للروبوتات في النماذج، وحساب لكل مشرف بصلاحية «مالك» أو «محرر»، وسجل تدقيق لكل تعديل.

## التشغيل محلياً

```bash
cd dalil-hama/public
python3 -m http.server 8080
# افتح http://localhost:8080
```

## النشر

الموقع ملفات ثابتة، فيمكن نشره على أي خادم:

- **Render (المستخدم حالياً):** موقع ثابت من هذا المستودع، مجلد النشر `dalil-hama/public`، ويُحدَّث تلقائياً مع كل دفع إلى الفرع.
- **خادمك الحالي (Caddy):** انسخ محتوى `public/` إلى مجلد واخدمه بـ `file_server`.

### ربط النطاق dalil-hama.majid.cfd

1. في Render: افتح الخدمة ← Settings ← Custom Domains ← أضف `dalil-hama.majid.cfd`.
2. عند مزوّد DNS: غيّر سجل `dalil-hama` إلى `CNAME` يشير إلى عنوان الخدمة على Render (`xxxx.onrender.com`).
3. يُصدر Render شهادة HTTPS تلقائياً خلال دقائق.

## البيانات

- `scripts/clean_import.py`: ينظّف ملف CSV من النسخة القديمة (توحيد الأرقام، وإعادة التصنيف، واستخراج الأحياء والإحداثيات) ويستورده. التفاصيل في `docs/data-cleanup-report.md`.
- النسخ الاحتياطي: من لوحة الإدارة ← «استيراد وتصدير» ← «تصدير CSV» أو «نسخة JSON كاملة».

## ملاحظات

- مفتاح Supabase الموجود في `config.js` مفتاح عام (publishable) وآمن للنشر، فالحماية مطبّقة داخل قاعدة البيانات.
- كلمة مرور المشرف لا تُحفظ في المستودع. غيّرها من «الإعدادات» بعد أول دخول.
- يُنصح من لوحة Supabase ← Authentication بإيقاف «Allow new users to sign up» (الحسابات تُنشأ من لوحة الإدارة فقط)، وتفعيل «Leaked password protection».

## المراجعة والجودة

خضع المشروع لمراجعة شاملة متعددة المحاور: الواجهة، ولوحة الإدارة، والأمان وقاعدة البيانات، وجودة البحث والبيانات. أكّد مراجعٌ مستقل كل ملاحظة قبل إصلاحها، وأُصلحت الملاحظات المؤكدة الـ36 كلها. أبرزها:
- استيراد نسخة الدليل القديم يضيف الجديد فقط ولا يمسّ البيانات المنظّفة.
- منع تنفيذ أكواد عبر أيقونات التصنيفات، وتنظيف الروابط في الواجهة وقاعدة البيانات.
- إغلاق ثغرة الاستيلاء على حساب مشرف عبر تسجيل بريده مسبقاً.
- عدّاد «الأكثر تواصلاً» يحتسب الجهاز الواحد مرة يومياً، فلا يمكن التلاعب بالترتيب.
- بحث أدق: «صيدلية المرابط» تعطي صيدليات لا عيادات «مقابل الصيدلية»، وفهم «أطباء/دكاترة/ميكانيكي/تاكسي/السمان/الكازية».
- لا يظهر شريط تمرير أفقي على أصغر الهواتف، وتباين الألوان يحقق معيار WCAG AA، والتحديثات لا تخلط ملفات قديمة بجديدة.
